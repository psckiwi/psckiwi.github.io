Orca — AI 코딩 에이전트 여러 명을
한 앱에서 동시에 지휘하는 작업장

Orca는 Stably AI가 만든 무료 데스크톱 앱이고, 오픈소스(프로그램 설계도인 코드가 공개됨)입니다. Claude Code·Codex 같은 AI 코딩 에이전트에게 일을 여러 개 동시에 맡기고, 각자 다른 작업 폴더(워크트리)에서 일하게 한 뒤, 결과를 한곳에서 확인·검토해 내보냅니다.

무료 · 오픈소스macOS · Windows · LinuxiOS · Android 앱쓰던 Claude·Codex 구독을 그대로 사용
아주 쉽게 말하면AI 도우미를 “직원”이라고 생각해 보세요. 여러 명에게 동시에 일을 시키면 빠르지만, 모두가 같은 책상에서 같은 서류를 고치면 엉망이 됩니다. Orca는 직원마다 책상(워크트리)을 따로 주고, 누가 일하는 중이고 누가 질문을 기다리는지 한 화면에 보여 주며, 끝난 결과를 검토해서 합치는 사무실입니다.
먼저 알아 둘 것Orca는 AI 모델도, 코드 없이 프로그램을 만들어 주는 도구(노코드)도 아닙니다. 이미 쓰고 있는 AI 에이전트와 git(코드 변경 이력을 기록하는 도구)을 그대로 쓰는 “작업장”이라, 결과를 판단하려면 기본적인 코드 지식이 있으면 좋습니다.

한 장 그림

하루 작업의 기본 순환

시작 전에 하나만: 에이전트는 기본적으로 허락을 묻지 않습니다명령을 하나씩 확인받지 않고 바로 실행합니다(Yolo 모드). 폴더를 나누는 것은 에이전트끼리 서로의 파일을 건드리지 않게 하려는 것입니다. 실행 전에 직접 확인하고 싶다면 설정 → Agents에서 Manual(매번 허락을 묻는 모드)로 바꾸세요.

이제 어디로 갈까요?

따라 하면서 배우려면 활용편이 가장 빠릅니다. 차근차근 읽으려면 이 순서로 보세요.

소개·용어→첫 3-에이전트 세션→워크트리 기초→채팅 화면→결과 검토

여기까지가 핵심입니다. 아래는 더 알고 싶을 때 읽으세요. 제목을 누르면 접을 수 있습니다.

꼭 알아야 할 말 8개

워크트리·브랜치·PR이 무슨 뜻인지

AI 코딩 에이전트

코드를 읽고 고치고 명령을 실행하는 AI 프로그램. Claude Code, Codex, Cursor CLI, Gemini 등.

터미널

글자로 명령을 입력하는 창. 대부분의 에이전트가 이 안에서 돌아갑니다.

저장소 · 커밋

변경 이력이 담긴 프로젝트 폴더와, “여기까지 저장” 하고 남기는 한 번의 기록.

브랜치

원본(main)을 건드리지 않고 따로 작업하는 이력의 갈래.

⭐ 워크트리

한 저장소의 브랜치를 별도 폴더에 꺼내 놓은 것. Orca의 기본 작업 단위. 화면에는 Workspace라고도 나옵니다.

diff

바뀌기 전과 후의 차이. 지운 줄은 빨강, 더한 줄은 초록.

PR

“내 변경을 원본에 합쳐 주세요” 하는 검토 요청(Pull Request).

CLI

글자 명령으로 쓰는 프로그램. Orca에도 orca 명령이 있어, 에이전트가 새 워크트리를 만드는 일 등을 직접 할 수 있습니다.

더 많은 용어(32개)는 가이드 용어표에 있습니다.

핵심 개념 5가지

폴더 나누기, 상태 표시, 권한 모드 등

📁1. 워크트리

할 일 하나 = 독립된 폴더 하나. 만들기 → 작업 → 검토 → 내보내기 → 정리. 터미널·브라우저 탭·화면 배치도 워크트리마다 따로 저장됩니다.

2장 워크트리

🤖2. 에이전트 세션과 상태

Orca는 에이전트마다 지금 일하는지·질문을 기다리는지·끝났는지 표시하고, 끝나면 알림을 보냅니다. 창을 하나씩 열어 볼 필요가 없습니다.

상태 표시

🔓3. 권한 모드

에이전트가 명령을 실행하기 전에 나에게 물을지 정합니다. 기본은 묻지 않고 실행(Yolo), Manual은 매번 허락을 묻는 모드, Auto는 일상적인 작업을 에이전트가 스스로 승인하는 모드입니다(Claude·Codex 등 일부만 지원).

권한 기본값

🪟4. 탭 · 분할 · 세션 복원

에이전트·터미널·브라우저·diff를 끌어서 나란히 배치. 앱을 꺼도 뒤에서 도는 관리 프로그램(데몬)이 에이전트를 살려 두고, 다시 열면 그대로 이어집니다(컴퓨터 재부팅은 예외).

세션 복원

🔎5. 빠른 이동

Cmd/Ctrl+P 현재 워크트리 파일 찾기, Cmd/Ctrl+J 모든 워크트리·탭 찾기, 탭 줄의 +로 열린 탭·파일·웹 주소·에이전트를 한 번에 검색.

빠른 이동
상태 표시 읽는 법: 작업 중 ? 나를 기다림(허락·질문) 완료 막힘·실패 쉬는 중

주요 기능

Orca로 할 수 있는 일 6가지

💬에이전트와 터미널

40여 개 에이전트를 쓸 수 있습니다(Claude Code·Codex 등). 터미널 대신 채팅 화면으로 지시하고, 지난 대화를 이어 가고, 계정을 바꿔 끼우고, 사용량·한도를 확인합니다.

3장

🌐내장 브라우저 · 디자인 모드

앱 안에 있는 웹 브라우저를 워크트리마다 따로 씁니다. 화면 요소를 클릭하면 그 정보가 에이전트 채팅으로 들어가 “이거 고쳐 줘”가 됩니다. 에이전트도 이 브라우저를 직접 조작합니다.

4장

📝편집과 보기

VS Code(널리 쓰이는 코드 편집기)와 같은 바탕의 편집기로 코드를 고치고 자동 저장합니다. 문서 편집기, 웹 페이지·PDF·이미지·표 파일 보기도 있고, 파일을 끌어다 프롬프트(AI에게 주는 지시문)에 넣을 수 있습니다.

5장

🔍리뷰와 배포

바뀐 줄마다 메모를 달아 한꺼번에 에이전트에게 돌려보냅니다(화면 이름 Annotate AI Diff). 커밋, 서버로 올리기(푸시), PR, 같은 곳을 고친 변경끼리 부딪칠 때 해결하기(병합 충돌), GitHub·Jira·Linear(코드·할 일 관리 서비스) 연결까지 앱 안에서 합니다.

6장

⌨️CLI · 자동화

orca 명령으로 사람도 에이전트도 Orca를 조작합니다. 정해진 시간에 지시를 실행하는 예약 자동화, 팀장 에이전트가 일을 나누는 오케스트레이션실험, 에이전트가 데스크톱 앱을 조작하는 Computer Use도 있습니다.

7장

📡원격 · 모바일

SSH(다른 컴퓨터에 원격으로 접속하는 방법)로 다른 컴퓨터에서 에이전트를 돌리거나, 늘 켜 둔 컴퓨터(서버)에 Orca를 띄워 둘 수 있습니다. 휴대폰 앱(iOS·Android)으로 알림을 받고 이어서 지시합니다.

8장

어디서 돌릴까 — 실행 방식 4가지

처음엔 기본값인 로컬이면 충분합니다
방식화면실제 작업(파일·에이전트)이럴 때
로컬 (기본)내 컴퓨터내 컴퓨터처음 쓸 때는 이것만 알면 됩니다
SSH (원격 접속)내 컴퓨터다른 컴퓨터성능 좋은 다른 컴퓨터(서버)에서 돌리고 싶을 때
원격 Orca 서버노트북·폰·브라우저 어디서나늘 켜진 서버어느 기기에서든 같은 작업을 이어갈 때
Cloud VM (클라우드의 가상 컴퓨터)내 컴퓨터필요할 때 만드는 임시 서버작업마다 깨끗한 환경이 필요할 때

그 밖의 주의점

공유 링크, 실험 기능, 사용 통계
링크는 비밀번호처럼원격 서버·휴대폰 연결(페어링) 링크나 스킬(에이전트가 설치해 쓰는 작업 안내서) 공유 링크는 받은 사람이 접속·설치할 수 있습니다.
실험 기능오케스트레이션·에이전트 대시보드·브라우저 확장 등은 설정 → Experimental에서 켜야 하고 바뀔 수 있습니다.
사용 통계Orca는 익명 사용 통계를 보냅니다. 코드·프롬프트는 보내지 않으며 설정에서 끌 수 있습니다.
