ego(lite) — 나와 AI 에이전트가
함께 쓰는 브라우저

ego(lite)는 내가 평소처럼 인터넷을 쓰는 동안, AI 에이전트(내 대신 명령을 실행하며 일하는 AI 프로그램 — Claude Code, Codex 등)가 같은 브라우저 안의 자기 공간에서 웹 작업을 대신 해 주는 브라우저입니다. Chrome과 뿌리가 같은 Chromium으로 만들었고, Citro Labs가 만듭니다. 이 한 장은 완전 가이드의 요점만 모은 것입니다.

무료 · 구독 없음계정 없이 사용macOS · Windows(베타)내 컴퓨터에서 실행에이전트·AI 모델은 내가 고름

1. 무엇을 하는 도구인가

에이전트에게 “이 사이트에서 이것 좀 해 줘”라고 맡기면, 에이전트가 ego(lite) 안의 Space(스페이스 — 에이전트 전용 작업 공간)에서 페이지를 열고, 읽고, 누르고, 입력합니다. 조사, 양식 채우기, 웹사이트에서 자료 모으기, 웹 앱 시험 같은 일입니다. 그동안 나는 내 탭에서 하던 일을 계속합니다.

2. 핵심 개념 네 가지

Space — 어디서 일하나

에이전트 전용 작업 공간. 새 창, 두 번째 프로필, 화면 없는 브라우저, 클라우드 세션이 아닙니다. 같은 ego(lite) 안에서 돌며 내 탭·마우스·키보드를 빼앗지 않습니다. 보통 작업 하나에 하나씩, 여러 개를 동시에 돌립니다. 가이드 2장

스냅샷 — 어떻게 읽나

페이지를 짧은 글로 옮긴 것. 원본 코드는 수만 토큰(AI가 읽는 글의 양 단위)까지 가지만 스냅샷은 보통 수백 토큰입니다. 단추·입력 칸마다 번호표(@N)가 붙습니다. 가이드 3장

ego-browser — 어떻게 조종하나

에이전트가 짧은 스크립트를 쓰면 “열기 → 읽기 → 누르기 → 보고”를 한 번의 호출로 실행합니다. AI와 주고받는 횟수가 줄어 작업이 빨리 끝나고 토큰이 덜 듭니다. 가이드 4장

넘겨받기 — 사람이 필요할 때

인증 번호, QR 로그인, 결제 확인 같은 단계에서는 에이전트가 멈추고 나를 부릅니다. 내가 그 Space에서 직접 처리하면 에이전트가 이어 갑니다. 가이드 2장

3. 시작하기 — 네 걸음

  1. 설치하고 첫 실행 설정 마치기처음 열면 ego(lite)가 컴퓨터에 설치된 에이전트를 찾아 ego-browser 스킬(에이전트용 사용 설명서 묶음)을 스킬 폴더(~/.agents/skills, ~/.claude/skills/)에 넣어 줍니다. 쓰던 브라우저의 로그인·북마크·비밀번호·확장 프로그램을 가져올지도 묻습니다. macOS가 키체인 암호를 여러 번 물을 수 있습니다.
  2. 에이전트 연결하기에이전트를 완전히 종료했다가 다시 연 뒤 대화창에 /ego-browser를 입력해 스킬을 불러옵니다. 에이전트가 ego(lite) 앱을 실행할 수 있도록 승인 없이 실행하는 권한(Codex의 Full access 등)을 켭니다. 이름은 에이전트마다 다릅니다(아래 6번 표).
  3. 첫 작업 맡기기문서의 첫 예시는 다음 문장입니다. 에이전트가 새 Space를 만들어 두 블로그를 읽고 요약을 돌려줍니다.
  4. 지켜보고 넘겨받기ego(lite) 오른쪽 위 Space 단추로 Space 관리 패널을 엽니다. 파란 빛이 나는 Space가 에이전트가 일하는 곳입니다. 들어가서 구경하거나, 로그인·인증처럼 내가 필요한 단계를 직접 처리합니다.
Use ego-browser. Please open the blog pages of OpenAI and Anthropic, check if there is any noteworthy information, and quickly summarize the main points of the latest articles for me.

뜻: ego-browser를 써서 OpenAI와 Anthropic의 블로그를 열고, 눈여겨볼 소식이 있는지 확인한 뒤 최신 글의 요점을 간단히 정리해 줘.

자세한 순서는 가이드 1장, 따라 하기는 활용편 시작하기와 실습 1에 있습니다.

4. 에이전트가 멈춰야 하는 순간

ego(lite)에 로그인해 둔 사이트는 에이전트도 보통 로그인된 화면으로 바로 엽니다. 그래서 더욱, 아래 상황에서는 에이전트가 멈추고 나에게 돌려줘야 합니다. 일을 맡길 때 “읽기만 하고 고치지 마”, “제출 전에 멈추고 확인받아”처럼 경계를 미리 정해 두면 좋습니다.

멈춰야 하는 상황예
본인 확인문자·이메일 인증 번호, QR 코드 로그인, 보안 키
돈이 오가는 일결제, 주문, 송금, 환불
되돌리기 어려운 변경게시, 삭제, 보관 처리, 한꺼번에 많이 고치기
권한을 내주는 일다른 앱이 내 계정에 접근하도록 승인하기
꼭 지킬 것 비밀번호나 인증 코드를 에이전트 대화창에 붙여 넣지 마세요. 로그인·인증은 에이전트 Space에서 내가 직접 합니다. ego(lite)는 CAPTCHA(사람인지 확인하는 검사)나 사이트의 보안 확인을 우회하지 않습니다.

5. 스냅샷과 일 맡기는 글

에이전트가 로그인 페이지를 읽으면 아래처럼 보입니다. 에이전트는 “@3에 입력, @5를 누르기”처럼 번호표로 동작합니다. 번호표는 그 스냅샷에서만 유효해서, 페이지가 바뀌면(이동, 새로 고침, 제출, 탭 전환 등) 스냅샷을 새로 찍어야 합니다.

스냅샷 예시 — 로그인 페이지
Page: Example - Log in URL: https://example.com/login @1 [heading] "Log in" @2 [form] @3 [input type="email"] placeholder="Email" @4 [input type="password"] placeholder="Password" @5 [button type="submit"] "Continue" @6 [link] "Forgot password?"
일 맡길 때 적을 다섯 가지
  • 대상 페이지나 사이트
  • 읽을 것, 채울 것, 누를 것, 내려받을 것
  • 하면 안 되는 것 (삭제, 게시, 결제, 메일 보내기 등)
  • CAPTCHA·결제·권한 화면에서 멈출지
  • 받고 싶은 결과의 모양 (표, 요약, 화면 사진, 파일 경로)
끝난 뒤 확인할 다섯 가지
  • 어느 페이지에 갔고 무엇을 했는지 밝혔는가
  • 확인할 수 있는 것(제목, ID, URL, 금액, 시각)이 들어 있는가
  • 내려받았다면 파일 경로를 알려 줬는가
  • 고치거나 제출하는 일이면 마지막 단계 전에 멈췄는가
  • 관련 페이지가 Space에 열려 있는가

작업이 끝나도 Space의 탭은 바로 닫히지 않아, 에이전트가 무엇을 보고 답했는지 확인할 수 있습니다. 다만 에이전트 작업 Space는 명령 없이 30분이 지나면 자동으로 닫힙니다(고정한 Space, 내가 만든 Space, 작업 중 나에게 넘겨진 Space는 제외).

결과가 이상하면 이전 답에서 추측을 이어 가게 하지 말고 지금 페이지를 다시 스냅샷하게 합니다. 스냅샷은 읽기만 하므로 페이지를 바꾸지 않습니다. 다만 화면 밖 내용, 이미지 속 글자, 복잡한 canvas(그림판처럼 화면에 직접 그리는 영역), 일부 iframe(페이지 안에 끼워 넣은 다른 페이지)은 다 읽히지 않을 수 있습니다. 가이드 3장

6. 에이전트별 연결 요약

순서는 모두 같습니다: ego(lite) 첫 실행 설정 → 에이전트 다시 열기 → 권한 넓히기 → 스킬 불러오기 → 일 맡기기. 이름과 위치만 다릅니다. 같은 에이전트라도 데스크톱 앱으로 쓰는 방법과 터미널(글자로 명령을 입력하는 창)에서 쓰는 방법이 따로 있는 경우가 많아 둘 다 적었습니다.

권한을 넓히면 에이전트가 명령을 묻지 않고 실행합니다. 믿는 에이전트와 작업에만 켜세요. 직접 만든 에이전트는 ego(lite)가 설치된 바로 그 컴퓨터에서 ego-browser 명령을 실행할 수 있는지가 핵심입니다. 가이드 5장 · 6장

7. 다른 도구와 무엇이 다른가

유형동작 방식ego(lite)가 나은 점 (문서 설명)
브라우저 확장 프로그램내가 쓰는 Chrome 창에 확장 프로그램으로 연결ego(lite) 자체가 브라우저라 짝짓기가 필요 없고, 에이전트는 내 탭이 아니라 자기 Space에서 일함
클라우드 브라우저제공 업체 서버에서 브라우저 실행내 컴퓨터에서 돌아 로그인이 기기에 남고, 브라우저 사용 시간 요금이 없음
에이전트 내장 브라우저AI 앱 안의 브라우저 창내 로그인이 있는 온전한 Chromium 브라우저이고, 어떤 에이전트든 쓸 수 있음
브라우저 CLI(명령으로 브라우저를 조종하는 도구)로그인 없는 브라우저를 한 단계씩 조종내 로그인에서 시작하고, 호출 한 번에 여러 동작을 실행
AI 브라우저브라우저 회사의 AI 도우미가 옆 창에내 에이전트가 조종하므로 내 컴퓨터의 코드·파일과도 함께 일함

만든 회사가 실제 사이트 31개 작업으로 다섯 도구를 같은 모델·같은 채점으로 비교한 측정(Real-World Bench) 결과는 아래와 같습니다. 회사 자체 측정이라는 점을 감안해서 보세요.

8. 개인정보 · 가격 · 지원 환경

항목내용
내 데이터ego(lite)는 내 컴퓨터에서 돕니다. Chrome에서 가져온 비밀번호·쿠키·방문 기록·북마크·확장 프로그램·프로필은 Chrome에서처럼 내 컴퓨터에 저장됩니다.
AI로 가는 것에이전트가 페이지를 다룰 때 그 페이지 내용을 읽어 자신이 쓰는 AI 모델로 보냅니다. 어떤 모델을 쓸지는 내가 고르며, 내 컴퓨터에서 도는 로컬 모델도 됩니다.
가격내려받기와 사용이 무료. 구독·작업당 요금·브라우저 사용 시간 요금 없음. 에이전트와 AI 모델 비용, 통신 비용은 지금처럼 내가 냅니다.
계정ego(lite)를 쓰는 데 계정이나 이메일이 필요 없습니다.
지원 환경macOS 기준. Windows는 베타로 내려받을 수 있고(Windows 빠른 시작 문서), Linux는 예정입니다. 제품 소개 문서에는 아직 “Windows·Linux 예정”이라고 적혀 있습니다.
곧 제공 예정성공한 작업 방법을 사이트별로 저장해 재사용하는 “경험 쌓기”(제한 베타).
주의에이전트에게 진짜 브라우저 조종 권한을 주는 것이므로, 믿을 수 있는 곳에서 받은 에이전트만 연결합니다.

9. 막힐 때 먼저 볼 것

증상먼저 할 일
스킬(/ego-browser)이 안 보인다ego(lite) 첫 실행 설정을 마쳤는지 확인하고, 에이전트를 완전히 종료했다가 다시 엽니다. Claude Code는 Code 모드인지, OpenClaw는 /ego_browser인지 봅니다.
스킬은 불러왔는데 ego(lite)가 안 열린다권한 설정이 6번 표대로 켜져 있는지 확인합니다. 터미널 화면이면 세션을 닫고 표의 명령으로 다시 시작합니다.
사이트가 로그인·인증을 요구한다에이전트 Space에 들어가 내가 직접 처리한 뒤, 에이전트에게 이어 하라고 말합니다.
번호표가 유효하지 않다고 한다페이지가 바뀐 것입니다. 스냅샷을 새로 찍게 합니다.

증상별 해결 순서는 활용편 실습 9·실습 10에 있습니다.
