Aside — 부탁한 일을
대신 해 주는 AI 브라우저

Aside는 내 웹사이트·계정·방문 기록을 써서 복잡한 일을 해내는 AI 브라우저입니다. 크롬이나 사파리처럼 웹을 보는 프로그램이면서, 글로 일을 맡기면 에이전트(사람 대신 브라우저를 조작해 일하는 AI)가 사이트에 로그인하고, 자료를 찾고, 파일을 만들어 줍니다.

macOS 15.0 이상Windows 10(22H2 이상) · 11무료 요금제로 시작쓰던 AI 구독 연결 가능
아주 쉽게 말하면보통 브라우저는 화면을 보여 주기만 하고 클릭은 전부 내가 합니다. Aside는 “급여 사이트에서 이번 달 명세서를 받아 줘”처럼 부탁하면 나 대신 클릭하고 입력해서 일을 끝내 놓는 브라우저입니다. 서비스마다 따로 연결 설정을 하지 않고, 내가 로그인해 둔 사이트를 나처럼 그대로 씁니다.

한 장 그림

일을 맡기는 입구 3개

① Ask AI — 새 탭에서

새 탭 입력창에는 Search(검색)와 Ask AI(AI에게 맡기기) 두 모드가 있습니다. 보던 페이지와 상관없이, 요청에 사이트·파일 이름을 적어 일을 맡길 때 씁니다. @를 치면 맥락(참고할 자료)을 붙일 수 있습니다.

브라우저로 쓰기

② 사이드 패널 — 보던 페이지에서

지금 보는 페이지가 일의 출발점일 때 씁니다. 패널에는 보던 페이지가 첨부로 붙어 페이지 제목과 호스트 이름(주소에서 사이트를 가리키는 부분)이 보이고, 첨부를 그대로 두면 Aside가 그 페이지를 읽고 거기서부터 일합니다. 첨부를 떼면 페이지 없이 시작합니다.

사이드 패널

③ 선택 · 올가미 단축 — 골라서 바로

글자를 고르면 Summarize(요약)·Translate(번역), 화면 한 부분을 올가미(둘러서 고르기)로 고르면 Copy code(코드 복사)·Search image(그림 검색) 단축을 쓸 수 있습니다. Settings → Lasso에서 고치거나 새로 만듭니다.

작업은 여러 단계를 이어 가다가 입력을 기다리거나, 승인을 요청하거나, 기다렸다가 다시 이어 갑니다. 일하는 도중에 내가 보낸 메시지는 둘 중 하나로 처리됩니다(Settings → Agents → Chat).

  • Queue(줄 세우기) — 지금 하던 일을 끝낸 뒤 반영합니다.
  • Steer(방향 틀기) — 하던 중에 바로 반영합니다. 다른 사이트를 쓰게 하거나 행동을 멈추게 할 때 씁니다.

좋은 요청 쓰는 법

Ask AI는 사이트, 원하는 결과, 지켜야 할 한계를 적을 때 가장 잘 됩니다. 돈·고객 정보·비밀번호·파일을 건드리는 일이면 한계를 꼭 적습니다.

✗ 너무 막연함

“내 결제 좀 처리해 줘.”원문: Handle my billing.

어느 계정인지, 무엇을 받을지, 어디에 둘지, 하면 안 되는 일이 없습니다.

✓ 사이트 · 결과 · 한계

“Rippling에 로그인해서 이번 달 급여명세서를 받아 PDF를 Downloads에 저장해 줘. MFA나 인증 코드가 필요하면 물어봐.”원문: Sign in to Rippling, get my paystubs for this month, and save the PDFs to Downloads. Ask if Rippling needs MFA or a verification code.

Rippling 은 원문 예시 속 서비스 이름입니다. 내가 급여명세서를 받는 사이트로 바꿔 읽습니다.

초안까지만 시키기보내기·게시·결제처럼 되돌리기 어려운 일은 요청 끝에 “보내기 전에 멈춰(Stop before sending)”를 붙여 초안까지만 만들게 합니다. 원문 예시 가운데 여럿이 이렇게 “…하기 전에 멈춰”로 끝납니다.

비밀번호 — 금고가 채우고, AI는 보지 못한다

  • Aside Vault(Aside의 비밀번호 금고)가 로그인 정보를 보관하고, 로그인 화면에서 맞는 것을 자동 입력합니다. 에이전트는 로그인 동작만 쓸 수 있고 비밀번호 원문은 받지 않습니다.
  • MFA(추가 인증 — 비밀번호 말고 한 번 더 확인하는 절차)·패스키(비밀번호 대신 내 기기로 인증하는 방식) 승인·CAPTCHA(사람인지 확인하는 문제)·본인 확인은 사람이 화면에서 직접 끝내야 합니다. 끝내면 작업이 이어집니다.
  • AI가 저장된 로그인 정보를 쓸 수 있는 때는 Settings → Passwords → Access policy for AI agents에서 고릅니다: Always allow(항상 — 기본값) · While unlocked(금고가 열려 있을 때만) · Never(안 함). 시크릿 작업에서는 에이전트가 금고를 쓰지 못합니다.
  • 1Password · Apple Passwords · Bitwarden · Chrome · Dashlane · Edge · Firefox · LastPass CSV에서 가져올 수 있습니다.

기억과 루틴

기억(Memory)

방문 기록·채팅·작업에서 맥락을 다시 꺼내 써서, 매번 처음부터 설명하지 않아도 됩니다. Settings → Memory에서 켜고 끄고, 일화 기억(그날그날 있었던 일의 기억)의 보관 기간을 Never forget · 30 days · 90 days 중에 고르고, 저장된 기억을 살펴보고 고칩니다.

반복 작업과 기억

루틴(Routines)

되풀이되는 일을 예약합니다. Cron routine은 정한 시각마다 새 작업을 시작하고, Heartbeat routine은 있던 채팅을 깨워 이어서 합니다. Settings → Routines에서 만들고·멈추고·지금 실행합니다. 무료 요금제는 켜 둔 루틴 3개까지입니다.

루틴
컴퓨터가 켜져 있어야 합니다루틴과 작업은 그 컴퓨터에서 돕니다. 유료 요금제여도 컴퓨터가 잠들거나 꺼지면 로컬 작업·루틴은 계속 돌지 않습니다. 클라우드로 넘기는 기능(Cloud handoff)은 아직 “Coming Soon”입니다.

여러 컴퓨터에서 — 오가는 것과 남는 것

채팅·작업 기록을 백업하거나 복원하는 기능은 아직 없고, Aside 폴더를 다른 컴퓨터로 복사하는 것도 지원되지 않습니다. 권한 · 개인정보 · 여러 기기 →

막혔을 때 먼저 볼 곳 3가지

작업이 나를 기다린다

작업을 열어 입력·승인 요청을 찾고, 요청한 행동을 살펴본 뒤 승인·거절하거나 답합니다. 사이트가 추가 인증을 요구하면 화면의 단계를 직접 끝냅니다.

작업이 엇나간다

후속 메시지를 보냅니다. 지금 바로 고쳐야 하면 Steer, 끝난 뒤에 반영해도 되면 Queue. 예: “결제 페이지 말고 청구서 페이지를 써. 메일은 보내지 마.”

자동 입력이 안 뜬다

Settings → Passwords에서 기본 비밀번호 관리자 사용, 자동 입력 켜짐, 시크릿 창 설정, 제외 도메인을 차례로 확인합니다.

문제 해결 전체 → · 버그 신고는 support@aside.com 또는 Settings → Send feedback.
