웹 서버, 한 장으로 쉽게

내 컴퓨터 속 페이지가 어떻게 멀리 있는 친구 화면에 뜰까요?

하나

웹 페이지는 알고 보면 파일 묶음이에요

웹 페이지는 글, 사진, 꾸밈이 담긴 파일 묶음이에요. 첫 화면을 담은 파일 이름은 보통 index.html이에요. 지금은 내 컴퓨터 안에만 있어서 친구는 볼 수 없어요.

둘

그래서 24시간 여는 가게에 파일을 맡겨요

친구가 언제든 보려면 늘 켜져 있고 인터넷에 늘 연결된 컴퓨터가 필요해요. 그런 컴퓨터가 서버예요. 내 파일을 서버에 옮겨 두면, 내 노트북이 꺼져 있어도 서버가 대신 보여 줘요.

셋

웹 서버 = 창고 + 점원

웹 서버라는 말은 두 가지를 가리켜요. 파일을 보관하는 컴퓨터, 그리고 그 안에서 "이 파일 주세요"라는 말을 알아듣고 건네주는 프로그램이에요. nginx와 Apache가 그런 점원 프로그램이에요.

넷

가게에는 숫자 주소와 이름이 있어요

인터넷에 연결된 컴퓨터마다 숫자 주소(IP 주소)가 있어요. 외우기 어려우니까 이름(도메인)을 붙여요. 이름을 숫자 주소로 바꿔 주는 인터넷의 전화번호부가 DNS예요.

다섯

"주세요" 하면 "여기요" — 이 대화 규칙이 HTTP

브라우저(크롬 같은, 웹을 보는 프로그램)가 "이 파일 주세요" 하고 요청하면, 서버가 "여기요" 하고 응답해요. 잘 됐으면 200, 그런 파일이 없으면 404라는 번호가 함께 와요. 이 대화 규칙의 이름이 HTTP예요.

여섯

그대로 건네기도, 그때그때 만들기도 해요

만들어 둔 파일을 그대로 건네는 방식을 정적, 요청을 받을 때마다 자료 창고(데이터베이스)에서 내용을 꺼내 그 자리에서 페이지를 만들어 건네는 방식을 동적이라고 해요. 처음에는 정적이 훨씬 쉬워요.

일곱

가게는 어디에 차릴까요?

내 컴퓨터를 서버로 쓸 수도 있지만 꺼지면 끝이에요. 그래서 보통 호스팅 업체(서버 공간을 빌려주는 회사)의 서버 공간을 빌리거나, GitHub Pages 같은 무료 게시 서비스에 파일을 올려요. 올리면 주소가 생겨요.

여덟

편지는 자물쇠 봉투에 넣어요 — HTTPS

주소가 https://로 시작하면 주고받는 내용이 암호로 바뀌어, 중간에서 엿봐도 알아볼 수 없어요. 자물쇠에 필요한 인증서는 Let's Encrypt라는 기관에서 무료로 받을 수 있고, GitHub Pages는 알아서 채워 줘요.

한 장으로 다시 보기

  1. 웹 페이지는 파일 — 첫 화면은 보통 index.html
  2. 웹 서버 — 늘 켜져 있는 컴퓨터 + 파일을 건네는 프로그램
  3. 주소 — 숫자 주소(IP 주소)에 이름(도메인)을 붙이고, DNS가 이어 줘요
  4. 요청과 응답 — "주세요" → "여기요"(200), 없으면 404. 규칙 이름은 HTTP
  5. 정적과 동적 — 그대로 건네거나, 그때그때 만들어 건네요
  6. 올릴 곳 — 처음에는 무료 게시 서비스가 쉬워요
  7. 자물쇠 — https://로 내용을 암호로 바꿔요
