git, 한 장으로 쉽게

파일의 "세이브"를 남기고, 친구들과 나눠 쓰게 해 주는 도구예요.

하나

게임 세이브처럼 파일의 버전을 남겨요

git은 버전 관리 도구예요. 파일이 바뀔 때마다 기록을 남겨 두니까, 예전 버전으로 돌아가거나 무엇이 언제 바뀌었는지 비교할 수 있어요.

둘

파일은 세 칸을 지나가요

git의 파일은 작업 책상(작업 폴더) → 장바구니(스테이징 영역) → 앨범(저장소) 세 칸을 차례로 지나가요.

셋

git status — 지금 상태를 비춰 보는 거울

git status를 치면 어떤 파일이 어느 칸에 있는지 알려 줘요. 헷갈리면 언제든 먼저 거울부터 보면 돼요.

넷

git add — 다음 사진에 넣을 것만 장바구니에 담기

git add는 "이 파일을 넣어"보다 "지금 이 내용을 다음 사진에 넣어"에 가까워요. 장바구니에 안 담은 변경은 사진에 찍히지 않아요.

다섯

git commit — 사진을 찍어 앨범에 붙이기

git commit은 장바구니에 담긴 것을 그 순간 그대로 사진(스냅숏)으로 찍어 앨범에 붙여요. 무엇을 했는지 메모(커밋 메시지, -m "메모")를 꼭 달아요.

여섯

git push — 내 앨범을 공용 앨범에 올리기

git push는 내 앨범의 새 사진들을 인터넷의 공용 앨범(원격 저장소)에 올려 친구들과 나눠요. 올릴 권한이 있어야 하고, 친구가 먼저 올렸다면 그걸 먼저 받아 내 것과 합친 뒤 다시 올려요.

한 장으로 다시 보기

  1. git status — 거울로 지금 상태 보기
  2. git add — 다음 사진에 넣을 것만 장바구니에 담기
  3. git commit -m "메모" — 사진 찍어 앨범에 붙이기
  4. git push — 공용 앨범에 올려 나누기
