# psckiwi.github.io

개념별 설명 문서를 모아 둔 사이트입니다. 프로그래밍을 모르는 사람도 읽을 수 있게 한국어로 씁니다.

**사이트:** https://psckiwi.github.io/

## 이 저장소에 있는 것

이 저장소는 **배포용**입니다. 빌드가 끝난 HTML 만 들어 있습니다.

| 파일 | 내용 |
| --- | --- |
| `index.html` | 전체 문서 목록 (사이트 첫 화면) |
| `sources.html` | 출처 목록 — 각 문서가 근거로 삼은 공식 문서 원문 링크 |
| `<주제>/<주제>-*.html` | 주제별 문서 (쉬운 설명·한눈에 보기·필수판·활용편·완전 가이드 중 고른 것) |
| `.nojekyll` | GitHub Pages 의 Jekyll 처리 끄기 |

모든 HTML 은 외부 리소스 없이 파일 하나로 열립니다.

## 원문과 원본에 대해

- 문서는 각 제품·기술의 공식 문서를 읽고 한국어로 다시 쓴 것입니다. 원문은 [출처 목록](https://psckiwi.github.io/sources.html)의 링크에서 보세요. 원문 사본은 이 저장소에 두지 않습니다.
- 문서 원본·빌드 스크립트는 별도 작업 저장소에서 관리합니다.

## 고치기

이 저장소에 직접 커밋하지 마세요. 작업 저장소에서 원본을 고치고 빌드해 push 하면 GitHub Actions 가 이 저장소로 자동 배포합니다. 직접 고친 내용은 다음 배포 때 덮어써집니다.
