Hermes Agent — 쓸수록
스스로 배우는 AI 에이전트

Hermes Agent는 Nous Research가 만든 AI 에이전트(말만 하는 챗봇과 달리, 도구를 써서 내 대신 일을 해 주는 AI 프로그램)입니다. 명령을 실행하고 파일을 고치고 웹을 찾아보며, 해 본 일은 스킬로, 나에 대해 알게 된 것은 기억으로 남겨 다음에 다시 씁니다. 이 한 장은 완전 가이드의 요점만 모은 것입니다.

Nous Research 제작무료 오픈 소스 · 모델 사용료는 따로터미널 + 메신저 20곳 이상기억 · 스킬로 배움제공자 · 모델은 내가 고름

1. 무엇을 하는 도구인가

나는 터미널이나 메신저로 말을 겁니다. Hermes는 내가 고른 모델(두뇌)에게 다음에 할 일을 묻고, 도구(손발)로 실제로 일을 합니다. 일이 실행되는 곳은 내 컴퓨터일 수도, Docker 상자나 다른 서버일 수도 있습니다.

2. 핵심 개념 여섯 가지

개념한 줄 설명자세히
제공자 · 모델모델을 빌려주는 서비스(provider)와 그 AI. hermes model 로 고르고 언제든 바꿉니다. 컨텍스트가 최소 64K 토큰인 모델이어야 합니다.1장
세션대화 한 묶음. 모두 자동 저장되고 hermes -c 로 이어 합니다. 일이 끝나면 /new 로 끊어 줍니다.2장
도구 · 툴셋도구는 손발(터미널·파일·웹 검색·기억 …), 툴셋은 그 꾸러미. hermes tools 로 플랫폼마다 켜고 끕니다. MCP 로 바깥 서비스의 도구도 꽂습니다.4장
기억MEMORY.md(2,200자 — 환경·배운 것)와 USER.md(1,375자 — 나에 대한 것). 세션을 시작할 때 읽으므로 방금 저장한 것은 다음 세션부터 보입니다.5장
스킬일하는 방법 설명서(SKILL.md). 평소엔 목록만 보고, 필요할 때만 본문을 읽습니다. 설치하면 /스킬이름 슬래시 명령이 됩니다.6장
게이트웨이메신저와 Hermes를 잇고, 세션 관리와 예약 작업 실행(60초마다 확인)까지 맡는 프로그램. 꺼지면 봇 답도 예약 작업도 멈춥니다.8장

3. 시작하기 — 네 걸음

문서의 원칙은 하나입니다. 대화 한 번이 제대로 되기 전에는 기능을 더 얹지 않는다.

curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash   # Linux · macOS · WSL2 설치
hermes setup --portal   # 로그인 한 번으로 모델 + Tool Gateway 도구 넷(웹 검색·이미지·음성·브라우저)
hermes                  # 대화 시작 (새 화면은 hermes --tui)
hermes --continue       # 방금 대화로 돌아오는지 확인 (줄여서 hermes -c)

설정은 두 파일에 나뉩니다. 비밀 값은 ~/.hermes/.env, 그 밖의 설정은 ~/.hermes/config.yaml. hermes config set 으로 넣으면 알맞은 파일로 저장됩니다. → 3장

4. 대화하며 자주 쓰는 것

하고 싶은 것방법
명령 목록 보기입력 칸에 / — /help·/model·/title·/sessions 부터
줄바꿈Alt+Enter 또는 Ctrl+J
일하는 중 방향 바꾸기새 메시지를 쓰고 Enter. 멈추려면 Ctrl+C 또는 /stop
대화가 너무 길어짐/compress 또는 /new. 컨텍스트 한도의 50%에 닿으면 자동 압축도 일어납니다
말투를 잠깐 바꾸기/personality teacher, 끌 때 /personality none. 늘 쓰는 성격은 SOUL.md
스킬 찾기 · 설치hermes skills browse → search → install (설치마다 보안 검사)

5. 맡겨 두기 — 예약 작업과 위임

예약 작업 (cron)

정해 둔 시간에 Hermes가 혼자 하는 일. 말로 부탁하거나 /cron add "every 2h" "Check server status" 처럼 만듭니다. 일정은 in 30m·every 2h·0 9 * * * 등. 매번 새 세션에서 돌므로 프롬프트는 혼자서도 이해되게 씁니다. 게이트웨이가 켜져 있어야 돕니다. → 7장

위임 (하위 에이전트)

큰일을 나눠 별도의 하위 에이전트에게 맡깁니다. 하위 에이전트는 새 대화에서 따로 일하고 요약만 돌려주며, 넘겨받은 쪽지에 적힌 것만 압니다. 기본 10개까지 동시에 돌고, /agents 로 지켜봅니다. → 7장

6. 메신저로 쓰기 — Telegram

  1. 봇 만들기Telegram 의 BotFather 에게 /newbot → 봇 토큰을 받습니다.
  2. 내 ID 알기@userinfobot 으로 숫자 사용자 ID 를 확인합니다(@이름 아님).
  3. Hermes 에 넣기hermes gateway setup 에서 Telegram 을 고르고 두 값을 넣습니다. TELEGRAM_ALLOWED_USERS 에 내 ID 를 꼭 넣습니다 — 기본은 “목록에 없는 사람은 전부 거절”.
  4. 켜 두기hermes gateway 로 켜고, 계속 켜 두려면 hermes gateway install 로 서비스로 설치합니다.

봇 토큰은 비밀번호처럼 다룹니다. 그룹에서 봇이 조용하면 Telegram 의 개인 정보 보호 모드부터 봅니다. → 8장

7. 안전장치

체크포인트는 hermes chat --checkpoints 나 설정 checkpoints.enabled: true 로 켭니다. 되돌리기 전에는 /rollback diff N 으로 미리 봅니다. → 9장

8. 미리 알아 둘 사실

항목내용
비용Hermes 자체는 무료 오픈 소스이고, 고른 제공자의 모델 사용료만 듭니다.
데이터대화·기억·스킬은 내 컴퓨터의 ~/.hermes/ 에 있고, 문서는 Hermes가 사용 통계를 수집하지 않는다고 적습니다.
설치 환경Linux·macOS·WSL2 는 명령 한 줄, Windows 는 PowerShell 명령, macOS·Windows 는 Hermes Desktop 설치 프로그램도 있습니다.
프로필설정·기억·세션을 따로 쓰는 별도 환경. 프로필 하나에는 에이전트 하나만, 봇 토큰도 따로.
옮기기hermes backup → hermes import. 전체 백업에는 API 키가 들어 있습니다.

9. 막힐 때 먼저 볼 것

증상먼저 할 것
hermes: command not found터미널을 새로 열거나 source ~/.zshrc(또는 ~/.bashrc). 설치에 sudo 를 붙이지 않습니다.
답이 비거나 이상함hermes model 로 제공자·모델·인증을 다시 확인합니다.
Context length exceeded/compress, 새 세션, 더 큰 컨텍스트의 모델.
봇이 조용함hermes gateway status → start → 기록 확인. 허용 목록에 내 ID 가 있는지.
“기억했다”는데 다음에 모름다음 세션부터 보입니다. 메신저에서는 /new 로 세션을 끊고, 기억 파일에 실제로 적혔는지 봅니다.
뭐가 문제인지 모르겠음hermes doctor → hermes model → hermes setup → hermes sessions list → hermes --continue → hermes gateway status 순서.

증상별 해결 순서는 활용편 실습 9·실습 10, 자주 묻는 질문은 10장에 있습니다.
