맡기기 전 점검표

사람 없이 돌리기 전에 묻는 다섯 가지(Claude Code 문서)에 위임서와 지시문 항목을 더했습니다.

  1. 끝이 어떤 모습인가 — 측정 가능한 끝 상태 하나, 명세 파일, 통과시켜야 할 실패 테스트. → 4장
  2. 스스로 확인할 수 있는가 — 통과/실패가 나오는 검사, 실행한 명령과 출력을 증거로. → 1장
  3. 무엇을 건드려도 되는가 — 권한 규칙, 샌드박스(바깥과 격리된 실행 공간), 워크트리(별도 작업 폴더), 올릴(푸시할) 수 있는 코드 갈래(브랜치) 하나. → 4장
  4. 무엇이 멈추게 하는가 — 최대 턴, 최대 비용, 지출 한도. → 4장
  5. 결과는 어디로 가고 누가 승인하나 — 병합·배포처럼 되돌릴 수 없는 일은 사람이 승인. → 4장
  6. 나눠 준다면 위임서 4요소가 있는가 — 목표 · 출력 형식 · 도구와 출처 · 작업 경계. → 5장
  7. 기준을 속이지 말라고 적었는가 — "테스트는 정답을 정의하지 않는다", 테스트를 지우거나 고치지 말 것, 불가능하면 알릴 것. → 8장
